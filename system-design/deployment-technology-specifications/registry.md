# Registry

The following deployment technology specifications are maintained by the Margo community and are available to application and device suppliers.

| Key | Status | Description | First Published | Last Updated | Reference |
|-----|--------|-------------|-----------------|--------------|-----------|
| `margo.org/deployment/helm` | Candidate | Helm-based application packaging and deployment for Margo |  |  | [Repository](https://github.com/margo/deployment-specification-helm/blob/pre-draft/README.md) |
| `margo.org/deployment/compose` | Candidate | Compose-based application packaging and deployment for Margo |  |  | [Repository](https://github.com/margo/deployment-specification-compose/blob/pre-draft/README.md) |

## Statuses

| Status | Description |
|--------|-------------|
| Candidate | Capture ideas and encourage innovation. Deployment technology specifications in the candidate state have not been officially released. |
| Ready | Available for adoption. Deployment technology specifications in the ready state have been released, with productization completed for related spec content, conformance testing, and reference implementation. |
| Deprecated | New usage discouraged. Existing deployments maintained. Transition planning recommended. |
| Retired | No new deployments. No longer supported by the Margo community. |
